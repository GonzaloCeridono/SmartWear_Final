# SmartWear - Backend API

Este es el servidor backend para la aplicación de e-commerce **SmartWear**. Provee una API RESTful construida con Node.js, Express y TypeScript, conectada a una base de datos no relacional en MongoDB Atlas.

## Tecnologías utilizadas

- **Node.js & Express:** Framework del servidor.
- **TypeScript:** Tipado estático para mayor escalabilidad.
- **MongoDB & Mongoose:** Base de datos NoSQL y modelado de objetos.
- **Bcryptjs:** Encriptación y seguridad de contraseñas.
- **JSON Web Tokens (JWT):** Autenticación y manejo de sesiones.
